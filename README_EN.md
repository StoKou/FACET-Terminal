# FACET-Terminal

[简体中文](README.md) | [English](README_EN.md)

**FACET: Preserving Source Intent and Executable State in Terminal Task Synthesis**

FACET is a framework for synthesizing coherent, complex, and verifiable terminal tasks by preserving source information and grounding task artifacts in a shared executable state.
